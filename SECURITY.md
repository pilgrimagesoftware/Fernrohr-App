# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in the Fernrohr App, please report it by email to paul@schifferers.net instead of using the issue tracker. This allows us to address the vulnerability before it becomes public knowledge.

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Any suggested fixes (if you have them)

We will acknowledge receipt of your report within 48 hours and keep you updated on our progress toward a fix.

## Supported Versions

Security updates are provided for the latest release only.

## Dependencies

We regularly update our dependencies to address known vulnerabilities. Dependencies are reviewed for security issues as part of the release process.
