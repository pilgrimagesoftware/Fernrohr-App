# Kubernetes icon set

The unlabeled resource icons, plus the infrastructure `node.svg`, from the
Kubernetes community icon set:
<https://github.com/kubernetes/community/tree/main/icons>, taken unmodified at
commit `e09b86d4a601cb612a36f770c3b291229ca2b44d`.

they are not part of it.
